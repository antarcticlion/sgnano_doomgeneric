# WAD の置き場

このフォルダには WAD を入れていません（大きいため）。ビルドには要りません。

sgnano で動かすときは、Freedoom かお持ちの Doom の WAD を、USB メモリなどの

```text
DoomFiles/freedoom1.wad      （Doom / Ultimate Doom の形）
Doom2Files/freedoom2.wad     （Doom II の形）
```

に置き、`DOOM.SGX` を同じドライブの好きな所（`DoomFiles` の隣など）に置いてください。
ファイラーで WAD を Enter するか、`DOOM.SGX` を Enter すると始まります。

Freedoom: <https://freedoom.github.io/>（0.13.0 で確認）

手元の確かめ用に、Freedoom 0.13.0 の配布の中身（`freedoom1.wad`・`freedoom2.wad`・`COPYING.txt`・`CREDITS.txt` など）を
`wads/freedoom-0.13.0/` に置くことがあります（git には入れません。`.gitignore`）。Freedoom は BSD-3-Clause（`COPYING.txt`）。
